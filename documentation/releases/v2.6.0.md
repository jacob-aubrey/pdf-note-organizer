# Notable 2.6

This release fixes Windows shortcut identity handling for downloaded copies and updates the GitHub regression workflow to use the same isolated, batched Windows test launcher as local validation.

## Download and launch

Download **Notable-2.6.0-windows-x64.exe**, save it in a permanent folder, and double-click it. Python is included. Windows 10/11 x64 and Microsoft Edge WebView2 Runtime are required for the embedded PDF reader.

The executable is unsigned. Compare its SHA-256 hash with **SHA256SUMS.txt** before running it: `Get-FileHash .\Notable-2.6.0-windows-x64.exe -Algorithm SHA256`.

## Changes

- Packaged launches create a **Notable** Start menu entry with the same Windows identity as the running app. Existing desktop, Start menu and taskbar shortcuts targeting that exact executable receive the matching identity while retaining their arguments, working folder and icon.
- The standard Notable Start entry follows the executable when a new copy is launched. Unrelated shortcuts and pins to other executable paths are retained. The app does not automatically pin itself or require administrator access.
- GitHub runs the regression suite on an inactive Windows desktop in separate process batches, and retains diagnostic logs for failed checks.
- The user manual and README include current 2.6 screenshots, launch guidance and taskbar pinning instructions. Both guides are bundled in Help and downloadable below.

## Upgrading and pinning

Close the previous version safely, then open the new executable. Your packaged library remains in `%LOCALAPPDATA%\PDF Note Organizer`; source launches normally use the checkout's `.local-data` folder. An explicit `PDF_NOTES_DATA_DIR` continues to override these defaults. Help and Settings identify the active library.

After launching once, open Windows Start, search for **Notable**, right-click it, and choose **Pin to taskbar** (under **More** on some Windows versions). If an old pin opens the previous executable, unpin that entry and pin the updated Start entry. A pin still targets a specific file, even when both versions share the same app identity. Managed Windows profiles may restrict shortcut registration; Notable still opens when it cannot update shortcuts.

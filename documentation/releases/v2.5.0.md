# Notable 2.5.0

Notable organizes research documents, collects PDF highlights, comments and handwriting into searchable notes, and generates Word notebooks. This Windows release packages the current app and both updated guides.

## Download and launch

Download **Notable-2.5.0-windows-x64.exe**, save it in a permanent folder, and double-click it. Python is included; no Python installation is required. Use Windows 10/11 x64. The embedded PDF reader requires Microsoft Edge WebView2 Runtime.

The executable is unsigned. Check that it came from this release and compare its SHA-256 hash with **SHA256SUMS.txt**. In PowerShell, `Get-FileHash .\Notable-2.5.0-windows-x64.exe -Algorithm SHA256` prints the executable's hash.

Packaged launches normally keep the saved library in `%LOCALAPPDATA%\PDF Note Organizer`. Source launches normally use the project's `.local-data` folder. **Help → Active library** or **Settings → Library & diagnostics** identifies the data folder actually in use. An explicit `PDF_NOTES_DATA_DIR` overrides the default. Back up an existing library before switching workflows; the new executable does not merge separate saved libraries.

## Included improvements

- Persistent PDF viewing with smooth search-result transitions, consistent fit-to-width navigation and separate PDF Find controls.
- A startup splash that holds the workspace until initial loading and layout are ready, with a crisp square one-pixel border.
- Clearer Library and review actions, contextual mapping, multiple-copy selection, visible checking placeholders and compact counted progress where totals are known.
- Tags, research collections, saved searches, citation and supplementary-file tools, accessible reading exports, and annotation history.
- Verified backup and separate restore, history-preserving database compaction, and review of eligible app-created recovery copies.
- Optional reMarkable cloud downloads, explicit folder mapping, and separately enabled PDF/folder transfers.
- Safe shutdown with a centered blocking dialog identifying remaining work.
- A procedural manual with annotated current screenshots, numbered actions, expected results and clickable task bookmarks. The README also explains local note storage, PDF indexing and tablet sync.

## Documentation and limits

Both PDF guides are bundled in **Help**, and are available as separate release downloads. Screenshots use generated example PDFs and an offline tablet catalog.

PDF search needs a text layer; image-only scanned documents need OCR before printed text can be searched. External PDF page jumps depend on the Windows default viewer. Tablet synchronization uses the reMarkable cloud protocol; optional sending creates new documents and does not continuously merge edits back into existing tablet PDFs.
